重文抑武的雙刃劍：宋初國策與積弱危機

公元960年趙匡胤建立北宋。為徹底根除唐末五代以來「藩鎮割據、武人篡奪」的亂局，宋初確立「強幹弱枝、重文抑武」國策。這雖然結束了內部動盪並造就璀璨的文人政治，卻也埋下「三冗」與「積貧積弱」的隱患，逼使北宋走上改革之路。

一

北宋的建立與中央集權政策

🚩 1. 陳橋兵變與統一方略

陳橋兵變（公元960年）

後周殿前都點檢趙匡胤奉命北上抵禦契丹與北漢聯軍，行至開封東北的陳橋驛時，部下發動兵變，為他披上黃袍（史稱「黃袍加身」）。趙匡胤回師逼後周恭帝禪位，定都開封（汴京），國號「宋」（史稱北宋），是為宋太祖。

「先南後北，先易後難」方略

採納宰相趙普建議，先攻滅物產豐富但軍力較弱的南方割據政權（如南平、後蜀、南漢、南唐等），集中全國財力後，再由宋太宗於979年攻滅依附契丹的北漢，結束五代十國分裂局面（唯燕雲十六州仍在遼國手中）。

🏛️ 2. 宋初「強幹弱枝」中央集權四大措施 目標：收兵權、削相權、制地方、集財權
二

宋代的「文人政治」

名言：「萬般皆下品，唯有讀書高」
🎓

1. 大幅擴充科舉取士

  • • 增加名額：每科錄取進士動輒數百人，遠超唐代（唐代每次僅二三十人）。
  • • 確立殿試：由皇帝親自主持最終考試，使及第者成為「天子門生」，效忠皇室。
  • • 糊名與謄錄：遮蓋考生姓名並派專人抄錄試卷，防止考官舞弊，打破門第限制，平民亦能入仕。
✒️

2. 崇文抑武，文臣掌軍

  • • 文官居高位：中央要職（如樞密使、三司使）及地方知州均以文官出任，武將地位低微，處處受文官牽制。
  • • 優厚士大夫：給予文官極高俸祿與恩蔭特權（一人做官，子孫親屬皆可得官）。
  • • 不殺大臣：宋太祖立下誓碑，戒律後世子孫「不得殺士大夫及上書言事人」。
⚖️

3. 臺諫合一，言路開放

  • • 強化監察權：御史台（監察百官）與諫院（規諫皇帝）職權擴大，允許「風聞言事」（無需確鑿證據亦可彈劾）。
  • • 士大夫政治自覺：讀書人以天下為己任，如范仲淹提出「先天下之憂而憂，後天下之樂而樂」，形成濃厚的議政與改革風氣。

📊 評估：宋代「文人政治」的正反影響

✅ 正面影響（長治久安與文化高峰）
  • 1. 徹底根除武人跋扈與地方割據，北宋三百餘年無藩鎮之亂。
  • 2. 社會流動性大增，寒門子弟可透過讀書改變命運。
  • 3. 推動教育、印刷術、理學、宋詞及科技（活字印刷、指南針、火藥）達致古代巔峰。
❌ 負面影響（行政低效與軍事積弱）
  • 1. 官僚膨脹：科舉與恩蔭過濫，導致官員人數激增，人浮於事。
  • 2. 黨爭不斷：士大夫政見不同，易演變成激烈派系鬥爭（如新舊黨爭）。
  • 3. 外行領導內行：文官不懂軍事卻指揮作戰，削弱軍隊戰鬥力。
三

北宋中葉的改革背景：「積貧」與「積弱」

至宋仁宗、宋神宗時期（11世紀中葉），宋初集權政策的弊端全面爆發，國家陷入嚴重的「積貧」（財政危機）與「積弱」（國防危機）困境，引發了范仲淹「慶曆新政」與王安石變法。

💸 一、「積貧」危機（財政入不敷出）

關鍵詞：三冗
1. 冗官（官員過多）： 分化事權、科舉大開及「恩蔭」制度，令官員數目激增，朝廷每年支付龐大俸祿。
2. 冗兵（軍隊龐大）： 採用「募兵制」，每逢災荒便招募流民當兵（荒年募兵），禁軍與廂軍總數高達一百二十多萬，軍費佔國家財政支出七成以上。
3. 冗費（開支浩繁）： 除官俸與軍費外，朝廷還要支付對遼、西夏的巨額「歲幣」，加上皇室奢華及祭祀賞賜，國庫日漸空虛。
4. 土地兼併嚴重： 官僚地主大量兼併農田並逃避賦稅，賦稅重擔全落在貧苦自耕農身上，農民起義頻生。

🛡️ 二、「積弱」危機（軍力不振、外患頻仍）

關鍵詞：更戍法、歲幣
1. 兵將分離，戰力低下： 推行「更戍法」，定期調動禁軍駐防地而將領不隨行，導致「兵不識將，將不識兵」，作戰時無法協調。
2. 守內虛外，邊防空虛： 精銳禁軍半數駐守京師開封以防內亂，邊境防禦力量相對薄弱，且失去燕雲十六州天險，無險可守。
3. 募兵素質參差： 軍隊吸納大量老弱流民，缺乏嚴格訓練，軍紀鬆散，戰鬥力遠遜於北方遊牧民族騎兵。
4. 遼、西夏交迫（屈辱求和）： 北宋對遼國（1004年訂「澶淵之盟」）及西夏作戰屢敗，被迫每年贈送大量銀兩、絹帛（「歲幣」）以換取和平。
歷史轉折點

「不變法，則國將亡」

內有「三冗」與農民起義，外有遼、西夏威脅。宋仁宗時范仲淹推行「慶曆新政」（因觸動官僚既得利益，僅一年便失敗）；至宋神宗即位，遂任用王安石推行更全面的「熙寧變法」，圖謀富國強兵。

四

考試高頻因果邏輯鏈（長答題必背）

考試常問：「試分析宋初中央集權政策如何導致北宋中葉的積貧積弱局面。」可按以下因果對應作答：

① 分化事權 + 擴充科舉/恩蔭 ➔ 機構重疊、「冗官」問題嚴重 ➔ 官俸激增 ➔ 積貧
② 荒年募兵（只增不減） ➔ 軍隊人數膨脹成「冗兵」 ➔ 軍費浩大 ➔ 積貧；軍隊老弱 ➔ 積弱
③ 更戍法 + 重文抑武（文官統兵） ➔ 兵將分離、指揮不靈 ➔ 對遼、西夏戰敗 ➔ 積弱
④ 戰敗求和（支付遼、夏歲幣） ➔ 形成龐大「冗費」 ➔ 財政進一步惡化 ➔ 積貧
